## How to sign

Signing is a comment on Your pull request. Open a pull request as usual; an automated check will ask
for a signature if one is not on file for Your GitHub account.

Post a **new comment** on the pull request containing exactly this sentence, on its own:

```
I have read the CLA Document and I hereby sign the CLA
```

The phrase must match exactly — the check compares the whole comment. Your GitHub username and the
signature are then recorded in `signatures/version1/cla.json` on the
[`main`](https://github.com/Omisen/invok/tree/main) branch of this repository, and the check turns
green. You sign once: later pull requests from the same account are recognised automatically.

If the check does not update after a signature or after a rebase, comment `recheck` on the pull
request to run it again.

A pull request touching more than one author's commits needs a signature from each of them.

If You cannot agree to these terms, please say so in the pull request. A contribution that cannot be
merged as code may still be valuable as a bug report or as a description of the fix, and neither of
those requires signing anything.
